# Diplom_2
# Дипломный проект: Тестирование API Burger Store

## Что протестировано
### Создание пользователя:
- создать уникального пользователя
- создать пользователя, который уже зарегистрирован
- создать пользователя и не заполнить одно из обязательных полей
### Логин пользователя:
- вход под существующим пользователем
- вход с неверным логином и паролем.
### Создание заказа:
- с авторизацией
- без авторизации
- ингредиентами
- без ингредиентов
- с неверным хешем ингредиентов

## Технологии
- **Java**: 11
- **Maven**: 3.9.0
- **JUnit**: 4.13.2
- **RestAssured**: 5.3.0
- **Allure**: 2.15.0
- **Lombok**: 1.18.28
- **JavaFaker**: 1.0.2

# Запуск тестов + генерация Allure-отчёта
mvn clean test
mvn allure:report

# Открыть отчёт в браузере
mvn allure:serve
